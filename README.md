# SeqProject2026

Brain-wide sequence analysis for IBL Neuropixels sessions, built around a cache-first pipeline for fast interactive exploration.

## What This Repository Does

This project computes neuron-level response timing, variability, and population coupling metrics from IBL sessions, then serves those results through dashboards.

Main contexts covered by the current pipeline:

- Task-aligned activity
- Spontaneous activity
- ITI windows
- Passive visual/auditory replay support
- Whisking-aligned analyses

## Recommended Workflow

Use this flow from a fresh clone:

1. Create and activate the conda environment.
2. Install dashboard packages not pinned in the environment file.
3. Configure processing scope in `notebooks/03_calc_dashboard.py`.
4. Run `03_calc_dashboard.py` to build/update per-PID caches.
5. Launch either the Streamlit dashboard or the lightweight local web dashboard.

## Quick Start

From the repository root:

```bash
conda env create -f environment.yml
conda activate Seq2026
pip install streamlit plotly plotly-resampler rastermap
python notebooks/03_calc_dashboard.py
streamlit run notebooks/04_dashboard.py
```

If you prefer the lightweight dashboard instead of Streamlit:

```bash
python web_dashboard/server.py
```

Open `http://127.0.0.1:8000`.

## Configure Processing Scope

Before running the cache build script, adjust these constants in `notebooks/03_calc_dashboard.py`:

- `COMPUTE_ALL`
- `PIDS`
- `SUBJECT`
- `REGIONS`
- `TAG`

Selection priority in the script is:

1. `COMPUTE_ALL=True` uses all insertions matching `TAG`
2. otherwise `PIDS` if provided
3. otherwise `SUBJECT` if provided
4. otherwise `REGIONS`

## Pipeline Outputs

Running `python notebooks/03_calc_dashboard.py` creates or updates:

- `data/dashboard_cache/<pid>.pkl` (dashboard-ready cache per probe insertion)
- `data/processed/<pid>_delay_results_dashboard.csv` (processed summary table)
- `data/raw/` (ONE/IBL cached datasets downloaded on demand)
- `results/figures/` (figures generated by analysis utilities)

The script is cache-aware and will reuse existing results when `config_calc` and `calc_version` match.

## Dashboards

### Streamlit Dashboard

```bash
streamlit run notebooks/04_dashboard.py
```

- Full interface for session-level and single-neuron exploration.
- Can use local cache and optionally fall back to remote Alyx lookups.

### Lightweight Local Dashboard

```bash
python web_dashboard/server.py
```

- Fast HTTP dashboard that reads existing `data/dashboard_cache/*.pkl` files.
- No recomputation; plotting is served on demand.

## Project Layout

```text
SeqProject2026/
  notebooks/
    03_calc_dashboard.py         # Main cache computation pipeline
    04_dashboard.py              # Full Streamlit dashboard
    00-11 analysis notebooks     # Context-specific analyses
  web_dashboard/
    server.py                    # Lightweight local HTTP dashboard
    static/                      # Frontend assets
  utils/                         # IO, analysis, plotting helpers
  data/
    raw/                         # ONE/IBL cache
    processed/                   # Processed per-PID tables
    dashboard_cache/             # Pickled dashboard caches
  results/
    figures/                     # Saved figures
```

## Notes

- First-time runs require network access to query Alyx/ONE and download datasets.
- Re-running `03_calc_dashboard.py` after changing config values is expected and will refresh caches as needed.
- Coupling analysis is based on spike-triggered population coupling with split-half reliability across contexts.
- Method reference: https://www.biorxiv.org/content/10.64898/2025.12.20.695676v2
